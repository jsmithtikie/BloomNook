# BloomNook

BloomNook employs self-healing distributed architecture and adaptive load balancing to optimize high-availability node management.

With BloomNook, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/BloomNook.git`
2. `cd BloomNook`
3. Install in editable mode: `pip install -e .`

## Configuration

BloomNook is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
